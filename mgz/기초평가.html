📘 네트워크 평가 문제 (총 20문항)

1.

AWS에 새로운 VPC를 구성하려고 한다. 사용할 CIDR은 172.31.0.0/16이고, 4개의 새로운 서브넷을 생성하려고 할 때 다음 중 오류가 발생하는 것은?

① 172.31.10.0/24

② 172.31.128.0/15

③ 172.31.240.0/23

④ 172.31.255.0/24

2.

네트워크상에 방화벽을 구축하고 있다. 방화벽 내부에 DNS 서버가 위치하고 있고, 외부에서 DNS 서비스를 사용하기 위해 방화벽에서 허용해야 하는 프로토콜과 포트는?

① TCP 80

② TCP 23

③ UDP 53

④ UDP 161

3.

로컬 시스템을 출발해서 외부 네트워크에 있는 시스템까지 트래픽이 도달하기 위해 반드시 필요한 주소는 무엇인가?

① MAC 주소

② IP 주소

③ 포트 번호

④ URL

4.

사설 네트워크의 시스템이 인터넷이 가능하도록 공인 IP 주소와 사설 IP 주소를 1:1로 매핑하는 NAT는 무엇인가?

① Dynamic NAT

② PAT

③ Port Forwarding

④ Static NAT

5.

다음 4개의 네트워크를 하나의 네트워크로 슈퍼네팅하시오.

  • 192.168.4.0/24
  • 192.168.5.0/24
  • 192.168.6.0/24
  • 192.168.7.0/24

6.

AWS의 어떤 퍼블릭 서브넷이 다음의 라우팅테이블을 사용할 때 해당 서브넷에 위치한 EC2에서 인터넷이 안되는 이유는 무엇인가?

7.

다음 주소가 속한 네트워크주소와 브로드캐스트 주소를 쓰시오. 172.31.141.96/20

8.

다음 중 VPN(Virtual Private Network)에서 제공하지 않는 것은?

① 암호화

② 인증

③ 무결성

④ 가용성

9.

Private Subnet에 위치한 EC2가 인터넷 통신을 해야 할 경우 사용해야 하는 서비스는 무엇인가?

① VPC Peering

② Transit Gateway

③ NAT Gateway

④ VPN

10.

윈도우나 리눅스에는 외부에서 수신되는 패킷을 필터링하기 위해 방화벽을 사용한다.

AWS EC2에서 이러한 방화벽 역할을 하는 서비스는 무엇인가?

① 10.0.0.1

② 172.20.10.5

③ 192.168.1.100

④ 172.40.1.10

12.

서브넷 마스크가 /24일 때 호스트에 할당할 수 없는 IP 주소는?

① 192.168.10.0

② 192.168.10.1

③ 192.168.10.100

④ 192.168.10.254

13.

서브넷 마스크의 역할로 가장 올바른 설명은?

① 포트 번호 관리

② 네트워크와 호스트 영역 구분

③ 패킷 암호화

④ 도메인 관리

14.

① ssh

② ping

③ curl

④ scp

15.

라우터(Router)의 주요 역할로 가장 적절한 것은?

① 같은 네트워크 내 통신

② 네트워크 간 패킷 전달

③ 포트 관리

④ 파일 공유

16.

AWS VPC에서 Public Subnet이 되기 위한 필수 조건은?

① 퍼블릭 IP 비활성화

③ NAT Gateway 연결

④ 보안그룹 인바운드 차단

17.

다음 중 NAT의 목적이 아닌 것은?

① 공인 IP 절약

② 사설 네트워크 보호

③ 내부 IP 은닉

④ 데이터 암호화

① FTP - TCP 20

② SSH - TCP 22

③ HTTP - TCP 80

④ Telnet - TCP 23

1.

다음 중 admin 사용자가 /etc/hosts 파일에 새로운 내용을 추가하는 명령으로 올바른 것은?

① echo “192.168.80.100 rocky1” > /etc/hosts

② sudo echo “192.168.80.100 rocky1” > /etc/hosts

③ echo “192.168.80.100 rocky1” | sudo tee /etc/hosts

④ echo “192.168.80.100 rocky1” | sudo tee -a /etc/hosts

2.

admin 사용자를 docker 그룹에 2차 그룹으로 추가하는 명령은?

① usermod -g admin docker

② usermod -g docker admin

③ usermod -ag docker admin

④ usermod -aG docker admin

3.

Windows와 Linux 서버 간에 CIFS 프로토콜을 이용한 파일 공유 서비스는?

① NFS

② SAMBA

③ FTP

④ SSH

4.

파일을 실행할 때 소유자의 권한으로 실행되도록 하는 퍼미션은?

① setuid

② setgid

③ setoid

④ sticky bit

5.

우분투에서 인터넷 저장소로부터 패키지를 설치할 때 사용하는 명령은?

① yast

② dnf

③ apt-get

④ yum

6.

shell.sh의 퍼미션이 rw-rw-r--일 때

소유자만 실행 가능하도록 설정하는 명령은?

① chmod 766 shell.sh

② chmod u+x shell.sh

③ chmod u-x shell.sh

④ chmod 775 shell.sh

7.

다음 보기와 같이 공식 이름 대신 별칭(Aliases)을 사용할 수 있도록 하는 Resource Record는 어느 것인가?

① A

② NS

③ CNAME

④ PTR

8.

test.tar.bz2 파일을 복원하는 명령으로 올바른 것은?

① tar xfz test.tar.bz2

② tar xfj test.tar.bz2

③ tar xfJ test.tar.bz2

④ tar xfZ test.tar.bz2

9.

systemctl 명령 중 부팅 시 서비스를 활성화하는 것은?

① start

② enable

③ status

④ restart

10.

다음 조건에 맞게 EC2에 접속하기 위한 ssh 명령을 작성하시오.

  • Key: mykey.pem
  • User: ec2-user
  • Public IP: 120.10.192.100

11.

현재 작업 중인 디렉터리를 절대 경로로 출력하는 명령과 옵션으로 올바른 것은?

① ls -p

② pwd

③ cd -p

④ echo $PWD

12.

파일과 디렉터리 목록을 숨김 파일까지 포함하여 상세 정보로 출력하는 명령은?

① ls

② ls -a

③ ls -l

④ ls -al

13.

현재 실행 중인 모든 프로세스를 전체 포맷으로 출력하는 명령은?

① ps

② ps -e

③ ps -ef

④ top -p

14.

디스크 사용량을 사람이 읽기 쉬운 단위(K, M, G)로 출력하는 명령은?

① df

② df -a

③ df -h

④ du -s

15.

현재 서버에서 열려 있는 포트와 리스닝 상태를 함께 확인할 수 있는 명령은?

① netstat -r

② ss -tuln

③ ps -ef

④ lsof

16.

파일의 소유자, 그룹, 권한을 함께 확인할 수 있는 명령으로 가장 적절한 것은?

① ls

② ls -a

③ ls -l

④ stat -f

17.

/var/log/messages 와 같은 시스템 로그 파일을 실시간으로 확인할 때 사용하는 명령은?

① cat /var/log/messages

② less /var/log/messages

③ tail -f /var/log/messages

④ head /var/log/messages

18.

현재 로그인한 사용자 계정과 UID, GID 정보를 함께 확인할 수 있는 명령은?

① whoami

② id

③ users

④ uname -a

19.

다음 조건으로 cron을 이용해서 일정을 등록할 때 알맞은 것은?

  • 매주 일요일 오전 4시에 점검 스크립트인 /etc/check.sh가 실행되도록 설정한다.

① 4 0 * * 1 /etc/check.sh ② 0 4 * * 1 /etc/check.sh ③ 4 0 * * 0 /etc/check.sh ④ 0 4 * * 0 /etc/check.sh

20.

리눅스 서버에서 외부 접속이 되지 않을 때 서비스 상태와 포트 리스닝 여부를 함께 확인하기에 가장 적절한 조합은?

② systemctl status + ss -tuln

③ ps + df -h

④ ifconfig + free
